# H1 Exploratory Regression Memo

**Date:** 2026-06-18
**Status:** EXPLORATORY — NOT confirmatory evidence
**Classifier:** batch1-only provisional (OOF AUC=0.7811, FH F1=0.4770)

---

## ⚠ Critical Framing

This is a **first exploratory association check**. It does not confirm H1.

- This is a **simple OLS** regression only.
- No fixed effects are included.
- No control variables are included.
- This is not a causal estimate.
- The result reflects a raw unconditional mean difference only.

The humor presence label (predictor) is generated by a **provisional batch1-only classifier**,
not gold-standard human labels for the full corpus. The classifier has:
- OOF AUC = 0.7811 (provisionally passes AUC threshold)
- Firm-held-out F1 = 0.4770 (limited cross-firm generalizability)
- Training: 1,482 batch1 human-coded posts only

---

## Research Design

| Item | Value |
|---|---|
| DV | log_total_engagement |
| Predictor | h1_humor_presence_pred_t50 (binary: 1 if prob ≥ 0.50) |
| Method | Simple OLS |
| Fixed effects | None |
| Control variables | None |
| Standard errors | Standard OLS SE |
| N observations | 65,245 posts |

**Model:**
```
log_total_engagement = β0 + β1 * h1_humor_presence_pred_t50 + ε
```

---

## Main Result

| Metric | Value |
|---|---|
| β0 (intercept) | 3.0713 |
| β1 (humor t50) | **0.9551** |
| SE | 0.0158 |
| t-statistic | 60.29 |
| p-value | < 0.001 |
| Significant at 5% | **yes** |
| N obs | 65,245 |
| R² | 0.0528 |

**Interpretation (exploratory):**
On average, humor-classified posts (t50) have log total engagement approximately
**0.955 higher** than non-humor posts. This is a simple mean difference without any
controls or fixed effects. It does not account for firm-level differences, time trends,
post-level characteristics, or any confounders.

This is a **raw unconditional association**. It cannot be interpreted as a causal effect
or as evidence that humor causes higher engagement.

---

## Limitations

1. **No controls:** The model includes no control variables. Confounders (firm identity,
   time period, post type, etc.) are entirely unaddressed.

2. **No fixed effects:** Between-firm and between-period variation is not removed. The
   observed association may reflect firm-level or time-level differences rather than
   within-firm humor effects.

3. **Large n / high power:** With n=65,245, even small differences produce very high
   t-statistics. Statistical significance is expected regardless of substantive importance.

4. **Provisional classifier:** batch1-only, OOF AUC=0.7811. Classifier noise attenuates
   estimated β toward zero.

5. **No causal identification:** Simple OLS is not a causal estimator.

---

## Next Steps

This simple OLS result is a first-pass check only. A more informative exploratory
analysis would add controls and fixed effects if and when directed by the user.
