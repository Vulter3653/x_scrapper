# Manifest

## Scripts

- `scripts/build_fortune100_post_master.py`: builds post-level master data, collection coverage, missingness, duplicate audit, and coverage report.
- `scripts/build_fortune100_humor_variables.py`: joins existing model-based classification to the post master without running new inference.
- `scripts/build_fortune100_firm_period_panel.py`: builds firm-month aggregates and H3 aggressive humor usage intensity variables.
- `scripts/build_fortune100_regression_ready.py`: builds post-level H1/H2 and firm-period H3 regression-ready datasets.
- `scripts/validate_20260618expand_outputs.py`: validates required files, columns, JSON, and package isolation.

## Engagement DV Note

The Fortune Top 100 expansion defines total_engagement as reply_count + repost_count/retweet_count + like_count/favorite_count + quote_count. bookmark_count is excluded from the default dependent variable because it is not consistently available in the Fortune Top 100 raw collection files. Therefore, the Fortune Top 100 expansion DV may not be identical to the earlier 20260615 Wendy's-only DV, where bookmark_count may have been included. Coefficients or mean values should not be directly compared between the Wendy's-only analysis and the Fortune Top 100 expansion without accounting for this DV difference.

## Data Outputs

- `data/processed/fortune100_post_master.csv`: deduplicated post-level master dataset.
- `data/processed/fortune100_post_master.json`: JSON copy of the post-level master dataset.
- `data/processed/fortune100_humor_variables.csv`: model-based humor presence/type variables and classification missing flags.
- `data/processed/fortune100_firm_period_panel.csv`: firm-month panel for usage-rate and H3 readiness analysis.
- `data/regression_ready/fortune100_post_level_regression_ready.csv`: H1/H2 post-level regression-ready file.
- `data/regression_ready/fortune100_firm_period_regression_ready.csv`: H3 firm-period regression-ready file.
- `data/regression_ready/fortune100_h1_h2_h3_regression_ready.csv`: compatibility alias of the post-level H1/H2 file.

## Diagnostics

- `data/diagnostics/fortune100_collection_coverage.csv`: firm-level collection coverage including empty and failed collections.
- `data/diagnostics/fortune100_missingness_summary.csv`: column missingness for post master.
- `data/diagnostics/fortune100_duplicate_tweet_audit.csv`: duplicate tweet id source rows before deduplication.
- `data/diagnostics/fortune100_humor_classification_coverage.csv`: firm/account classification availability.

## Reports

- `reports/coverage_diagnostics.md`: coverage summary generated by the post master builder.
- `reports/variable_construction.md`: variable construction rules.
- `reports/model_free_evidence.md`: planned descriptive diagnostics.
- `reports/h1_h2_h3_analysis_plan.md`: regression design and readiness rules.
- `reports/limitations_and_claim_boundaries.md`: claim boundaries.
