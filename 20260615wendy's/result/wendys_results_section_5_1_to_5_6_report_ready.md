## 5.3 H1 결과: 유머 게시물의 소비자 참여도 효과

H1은 유머 게시물이 비유머 게시물에 비해 더 높은 소비자 참여도(Consumer Engagement proxy)를 보인다는 가설이다. 전체 978개 게시물을 대상으로 유머 여부(유머예측이진)를 독립변수, log1p(좋아요수 + 리트윗수 + 답글수 + 인용수 + 북마크수)를 종속변수로 하는 OLS 회귀분석을 실시하였다(TABLE 1 참조).

시간 고정효과 및 게시물 형식 통제변수(텍스트길이, 해시태그수, 멘션수)를 포함한 주요 모형(Model 3, N = 978)에서 유머 게시물의 참여도 효과는 β = 0.2918***, SE = 0.1111, *p* = 0.0088로 나타났다. R² = 0.249, Adjusted R² = 0.214으로, 시간 및 형식 통제 후에도 유머 게시물이 비유머 게시물에 비해 유의미하게 높은 참여도를 보였다.

인간 코딩 검증 표본(Model 6, N = 597)에서도 동일한 방향의 유의한 효과가 확인되었다 (β = 0.3171**, SE = 0.1463, *p* = 0.0307). 이는 모델 기반 분류에 한정되지 않는 일관된 패턴임을 시사한다.

**결론: H1 지지됨 (Supported)**

## 5.4 H2 결과: 공격적 유머의 참여도 우위

H2는 공격적 유머 게시물이 기타 유머 게시물에 비해 더 높은 소비자 참여도를 보인다는 가설이다. 모델 기반으로 유머로 분류된 게시물 564개를 표본으로, 공격적 유머 여부(H2공격적유머모델더미)를 독립변수로 하는 OLS 회귀분석을 실시하였다(TABLE 2 참조).

시간 고정효과 및 통제변수를 포함한 주요 모형(Model 3, N = 564)에서 공격적 유머 게시물의 참여도 효과는 β = 0.4056***, SE = 0.1469, *p* = 0.0060로 나타났다. R² = 0.319, Adjusted R² = 0.262으로, 기타 유머 대비 공격적 유머의 유의미한 참여도 우위가 확인되었다.

인간 코딩 검증 표본(Model 6, N = 278)에서도 공격적 유머의 효과가 일관되게 확인되었다 (β = 0.6405***, SE = 0.1915, *p* = 0.0010).

**결론: H2 지지됨 (Supported)**

## 5.5 H3 결과: 유머 사용 강도의 조절 효과

H3는 개별 유머 게시물의 참여도 효과가 동일 분기 내 유머 사용 강도(Intensity: LOO 유머 비율)에 따라 역 U자형(inverted-U)으로 조절된다는 가설이다. H3 분석 표본(N = 960, 25개 분기)에서 유머비율LOO분기를 평균중심화한 Intensity_c와 그 이차항(Intensity_c²), 그리고 유머 여부와의 상호작용항(Humor × Intensity_c, Humor × Intensity_c²)을 포함한 조절 모형을 추정하였다(TABLE 3 참조).

H3 지지 조건: β4 > 0 AND β5 < 0, both *p* < .05

시간 고정효과 및 통제변수를 포함한 주요 모형(Model 3, N = 960)에서 β4 (Humor × Intensity_c) = 1.4176*, SE = 0.7997, *p* = 0.0766이며, β5 (Humor × Intensity_c²) = 1.9648, SE = 3.8657, *p* = 0.6114로 나타났다. R² = 0.260, Adjusted R² = 0.222.

β4가 양수(1.4176)로 추정되어 방향은 일부 일치하나 *p* = 0.0766로 .05 유의수준을 충족하지 못하며, 핵심 이차 상호작용항 β5가 **양수(+1.9648)**로 추정되어 역 U자형 조절 방향 자체가 성립하지 않는다. β5의 부호가 예측과 반대 방향이고 유의하지 않으므로, H3 지지 조건(β4 > 0 AND β5 < 0, both *p* < .05)은 충족되지 않는다.

β4가 10% 수준에서 양수 방향을 보이더라도, β5가 양수인 상황에서 이를 '부분 지지(partial support)'로 해석하는 것은 적절하지 않다. 역 U자형 조절 패턴 자체가 확인되지 않으므로 H3는 기각된다.

**결론: H3 지지되지 않음 (Not Supported)**
